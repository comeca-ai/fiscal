# P2 · Rede de Créditos (placeholder)

Serviço separado do P1 — `p2.app`, CNPJ próprio. Só consome o **Passaporte assinado** emitido pelo P1; nunca acessa os dados do P1.

**Regra de ouro:** este serviço só liga quando existirem **≥ 3 passaportes rating A/B reais** e o **Gate 0 jurídico** estiver aprovado.

Escopo da POC (ver `docs/Especificacao-Final-v1.0.pdf`, §02): vitrine anonimizada (rating, sem preço) → matching por predicado legal (art. 73/84) → interesse bilateral → data room → proposta indicativa. Nada é transferido, liquidado ou homologado aqui — todo desfecho é "apto para análise".
